### H1: Type mismatch en update() - MERGE INCORRECTO
**File**: `src/domains/cliente/cliente.ts` línea 324
```typescript
// INCORRECTO:
const existing = await prisma.socio.findUnique({...});  // ← Prisma Socio
const merged = { ...existing, ...data };  // ← Mezcla Socio + Cliente
const validation = validateCliente(merged);  // ← Falla: email/membresiaAsignada/estadoCuenta undefined
```

**Causa**: 
- `existing` tiene: `usuarioId`, `membresiaAsignadaId`, `estadoCuota`
- `data` tiene: `nombre`, `email`, `membresiaAsignada`, `estadoCuenta`
- merge crea: `email=undefined`, `membresiaAsignada=undefined`, `estadoCuenta=undefined`

**Impacto**: 
- ❌ UPDATE SIEMPRE FALLA
- ❌ T-012 PUT endpoint rechaza todo
- ❌ T-013 form no puede editar clientes

**Solución**:
```typescript
const existing = await prisma.socio.findUnique({...});
const existingCliente = this.mapSocioToCliente(existing);  // ← PRIMERO mapear
const merged = { ...existingCliente, ...data };  // ← AHORA merge es válido
const validation = validateCliente(merged);  // ← Funciona correctamente
```

### H2: estadoCuenta nunca persiste
**File**: `src/domains/cliente/cliente.ts` línea 358-366
```typescript
const updateData: any = {};
if (data.nombre !== undefined) updateData.nombre = data.nombre;
if (data.dni !== undefined) updateData.dni = normalizeDNI(data.dni);
if (data.telefono !== undefined) updateData.telefono = data.telefono;
if (data.email !== undefined) updateData.email = data.email;
if (data.membresiaAsignada !== undefined)
  updateData.membresiaAsignadaId = data.membresiaAsignada;
// ❌ FALTA: estadoCuenta
```

**Causa**: 
- No hay mapeo de `data.estadoCuenta` → `updateData.estadoCuota`
- Prisma Socio usa columna `estadoCuota`, Cliente domain usa `estadoCuenta`

**Impacto**: 
- ❌ Usuario cambia estado a "Inactivo"/"Bloqueado" pero se IGNORA
- ❌ T-013 form estado transition no persiste
- ❌ Dato incompleto en BD

**Solución**:
```typescript
// Agregar función de mapeo (inversa a mapEstadoCuotaToEstadoCuenta):
function mapEstadoCuentaToEstadoCuota(estado: EstadoCuenta): string {
  switch (estado) {
    case "Activo": return "AL_DIA";
    case "Inactivo": return "VENCIDO";
    case "Bloqueado": return "DENEGADO";
    default: return "AL_DIA";
  }
}

// En update():
if (data.estadoCuenta !== undefined) {
  updateData.estadoCuota = mapEstadoCuentaToEstadoCuota(data.estadoCuenta);
}
```

### H4: Usuario huérfano al eliminar Socio
**File**: `src/domains/cliente/cliente.ts` línea 388-393
```typescript
async delete(id: string): Promise<boolean> {
  const prisma = await this.getPrisma();
  const existing = await prisma.socio.findUnique({ where: { id } });
  if (!existing) return false;
  
  await prisma.socio.delete({ where: { id } });  // ❌ Usuario queda huérfano
  return true;
}
```

**Causa**: 
- Socio.usuarioId → Usuario.id (Foreign Key)
- Al eliminar Socio, Usuario no se elimina

**Impacto**: 
- 🟡 Usuario fantasma en tabla `usuarios`
- 🟡 Email UNIQUE bloqueado forever
- 🟡 No puedes crear nuevo usuario con ese email

**Solución**: 
```typescript
async delete(id: string): Promise<boolean> {
  const prisma = await this.getPrisma();
  const existing = await prisma.socio.findUnique({ where: { id } });
  if (!existing) return false;
  
  // Transacción: eliminar Usuario + Socio juntos
  await prisma.$transaction([
    prisma.socio.delete({ where: { id } }),
    prisma.usuario.delete({ where: { id: existing.usuarioId } }),
  ]);
  return true;
}
```
